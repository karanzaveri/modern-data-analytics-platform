# Modern Data Analytics Platform

An end-to-end analytics engineering project demonstrating modern data ingestion, transformation, orchestration, analytics, automation, and AI-assisted workflows.

## Planned Stack

- Python
- SQL
- BigQuery
- dbt
- Apache Airflow
- Git and GitHub
- GitHub Actions
- Docker
- REST APIs
- Power BI
- AI and LLM workflows

## Project Goal

Build a production-style analytics platform that ingests transactional and external API data, transforms and validates it, creates reusable analytical datasets, and powers dashboards and automated AI-generated business insights.
